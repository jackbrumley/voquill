# Contributing to FOSS Voquill

Thank you for considering contributing to Voquill. This project exists to keep dictation free, private, and open for everyone.

Forks and commercial use are permitted in accordance with AGPLv3, with the intention that improvements to the project remain available to the wider community.

## Philosophy

Voquill is designed to be truly free and open-source software. Before contributing, please review the core principles in the [README](README.md):

- No accounts, subscriptions, or paid tiers
- No cloud dependencies or data collection
- Privacy-first, local-first architecture
- AGPLv3 ensures all derivatives remain open source

## Code of Conduct

Be respectful, constructive, and collaborative. This project aims to be a welcoming space for everyone contributing to free and open-source software.

## How to Contribute

1. **Fork** the repository.
2. **Create a feature branch** from `main`.
3. **Make your changes**, following the conventions in [AGENTS.md](AGENTS.md).
4. **Run the pre-submit checks**:
   - `cargo fmt`
   - `cargo check`
   - `cargo clippy`
   - `npm run lint`
   - `npm run typecheck`
5. **Submit a pull request** with a clear description of your changes.

## Questions?

Open an issue or start a discussion on GitHub.
